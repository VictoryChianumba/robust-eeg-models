Artifacts:
- checkpoint.pth: model+optimizer state_dict
- curves.json: train/val accuracy/loss per epoch
- test_logits_clean.npy: logits on test set (clean)
- test_loss_vector.npy: per-sample CE loss on test set (clean)
- y_test.npy: test labels
- rng_state.pkl: RNG snapshots (numpy/torch)
- splits.json: train/val/test indices (no leakage)
- preprocessing.json: channelwise stats
- attack_metadata.json: to be populated after attacks
- meta.json: model/subject/seed, environment fingerprint
